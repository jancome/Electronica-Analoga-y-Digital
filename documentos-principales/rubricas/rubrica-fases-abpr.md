# Rúbrica orientadora de las fases ABPr

Esta rúbrica presenta criterios generales. La ponderación específica podrá ajustarse en cada corte sin cambiar los productos institucionales.

## Fase 1 – Preproyecto ABPr 1

| Criterio | Evidencia esperada |
|---|---|
| Comprensión del problema | Situación específica, justificación y beneficiarios. |
| Formulación | Objetivos y requerimientos claros. |
| Arquitectura | Diagrama de bloques coherente. |
| Diseño analógico | Rectificación, filtrado, regulación, protección y control. |
| Cálculos y simulación | Procedimientos correctos y resultados interpretados. |
| Investigación | Fuente técnica, referencia y aplicación. |
| Trabajo en equipo | Roles, aportes y dominio individual. |

## Fase 2 – Preproyecto ABPr 2

| Criterio | Evidencia esperada |
|---|---|
| Diseño lógico | Variables, tabla de verdad y expresión booleana. |
| Simplificación | Procedimiento correcto y justificado. |
| Simulación | Funcionamiento comprobado en diferentes casos. |
| Protoboard | Montaje funcional, ordenado y seguro. |
| Medición | Comparación entre salida esperada y medida. |
| Integración | Relación con la etapa analógica y el problema. |
| Mejora | Registro de fallas y plan de corrección. |
| Dominio individual | Cada integrante explica el circuito. |

## Fase 3 – Proyecto final ABPr

| Criterio | Evidencia esperada |
|---|---|
| Solución del problema | El proyecto responde a la necesidad seleccionada. |
| Funcionamiento | Prototipo físico estable y demostrable. |
| Integración | Coherencia entre alimentación, control y lógica digital. |
| Maqueta | Presentación organizada, segura y relacionada con la aplicación. |
| Correcciones | Evidencia de mejoras posteriores a la retroalimentación. |
| Simulación y mediciones | Coherencia con el montaje físico. |
| Informe y video | Documentación técnica completa. |
| Sustentación | Dominio grupal e individual. |

## Principio de evaluación formativa

La calificación de la Fase 3 corresponde al estado final del proyecto. No se calcula como suma de las calificaciones obtenidas en las fases anteriores.
