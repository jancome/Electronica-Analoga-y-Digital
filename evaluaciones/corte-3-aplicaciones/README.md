# Corte 3 – Aplicaciones digitales, secuenciales y proyecto final

Esta carpeta reúne los avisos e instrumentos del tercer corte. Los estudiantes pueden consultar fechas, pesos y temas generales. Los enunciados específicos de quizzes y talleres se publicarán en la fecha indicada a las **2:00 p. m. hora Colombia**.
