# Presentaciones semanales – Electrónica Analógica y Digital 2026-2

Esta carpeta reúne la estructura oficial para las presentaciones de las 17 semanas del curso.

Las presentaciones se diseñan como apoyo visual para la clase. No reemplazan el marco teórico, las guías de laboratorio ni la explicación del docente.

## Enfoque ABPr

Cada presentación debe mostrar:

1. Semana, unidad, corte y fase.
2. Pregunta detonante o aplicación real.
3. Resultado de aprendizaje.
4. Recuperación breve de conocimientos previos.
5. Conceptos esenciales.
6. Ejemplo guiado.
7. Actividad de cálculo, simulación, medición o montaje.
8. Conexión con la situación problema.
9. Evidencia ABPr esperada.
10. Errores, seguridad y pregunta de salida.

## Situación problema

> **¿Cómo diseñar e implementar un sistema electrónico analógico-digital, de bajo costo y bajo consumo, que permita supervisar, indicar o controlar una variable relacionada con el uso eficiente de la energía o de los recursos en Barranquilla y la región Caribe?**

## Criterios visuales

- Formato 16:9.
- Una idea central por diapositiva.
- Priorizar diagramas, circuitos, tablas y formas de onda.
- Evitar párrafos extensos.
- Mantener contraste alto y tamaño legible.
- Incluir fuentes de imágenes y hojas de datos cuando corresponda.
- Usar la notación de negación mediante barra superior: `A̅`.
- Diferenciar visualmente teoría, actividad y evidencia ABPr.
