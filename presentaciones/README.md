# Presentaciones semanales

Esta carpeta reúne las presentaciones de las 17 semanas de **Electrónica Analógica y Digital – 2026-2**.

Las diapositivas son apoyo visual para la clase y se complementan con los marcos teóricos, las guías de laboratorio y las explicaciones del docente.

## Organización por fases

| Fase | Semanas | Enfoque |
|---|---:|---|
| Fase 1 | 01–05 | Formulación, etapa analógica y simulación inicial. |
| Fase 2 | 06–11 | Diseño lógico, simulación y protoboard. |
| Fase 3 | 12–17 | Integración física, maqueta, pruebas y sustentación. |
